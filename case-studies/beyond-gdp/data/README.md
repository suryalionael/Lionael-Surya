# Data

## `raw/`

Untouched files as downloaded by [`R/01_ingestion.R`](../R/01_ingestion.R) directly from official sources. Never edited by hand. Re-running the ingestion script overwrites these files with a fresh pull.

- `WHR26_Data_Figure_2.1.xlsx` — World Happiness Report 2026, Figure 2.1 data (life evaluation + factor decomposition), from `files.worldhappiness.report`.
- `wb_countries.csv` — World Bank's list of 217 non-aggregate countries/economies.
- `worldbank_indicators_raw.csv` — long-format pull of 7 World Bank indicators, 2005–2025, for all 217 economies.
- `INGESTION_MANIFEST.json` — source URLs, indicator codes, retrieval timestamp, and SHA-256 checksums for every raw file, for reproducibility.

## `processed/`

Cleaned, joined, analysis-ready datasets produced by `R/02_cleaning.R` and `R/03_joining.R`. Regenerated by the pipeline; never hand-edited. See [`docs/DATA_DICTIONARY.md`](../docs/DATA_DICTIONARY.md) for column definitions and [`docs/DECISION_LOG.md`](../docs/DECISION_LOG.md) for why specific variables were included or excluded.

Source documentation for the underlying data — coverage, licensing, join feasibility — lives in [`docs/DATASET_RESEARCH.md`](../docs/DATASET_RESEARCH.md) (Phase 0 research, not repeated here).
